# Python Intermediário - Aplicações Práticas

## 📋 Sobre o Projeto
Coleção de scripts Python que demonstram a aplicação de conceitos intermediários de programação para resolver problemas do mundo real, com foco em cálculos, classificações e conversões úteis.

## 🚀 Tecnologias Utilizadas
- **Python 3**
- **Estruturas Condicionais Avançadas**
- **Cálculos Matemáticos Aplicados**
- **Validação de Dados**

## 📁 Aplicações Desenvolvidas

### 1. Área da Circunferência
- **Arquivo:** `1_area_circunferencia.py`
- **Descrição:** Calcula a área de uma circunferência usando fórmula matemática
- **Habilidades:** Matemática aplicada, constantes

### 2. Classificador de Idade
- **Arquivo:** `2_classificador_idade.py`
- **Descrição:** Classifica pessoas em faixas etárias (criança, adolescente, adulto, idoso)
- **Habilidades:** Estruturas condicionais múltiplas

### 3. Calculadora de IMC
- **Arquivo:** `3_calculadora_imc.py`
- **Descrição:** Calcula Índice de Massa Corporal e classifica o resultado
- **Habilidades:** Cálculos de saúde, categorização

### 4. Conversor de Temperatura
- **Arquivo:** `4_conversor_temperatura.py`
- **Descrição:** Converte entre Celsius e Fahrenheit
- **Habilidades:** Fórmulas de conversão, opções do usuário

### 5. Verificador de Ano Bissexto
- **Arquivo:** `5_ano_bissexto.py`
- **Descrição:** Determina se um ano é bissexto seguindo regras calendárias
- **Habilidades:** Lógica complexa, operadores lógicos

### 6. Calculadora de Comissão
- **Arquivo:** `6_calculadora_comissao.py`
- **Descrição:** Calcula comissões de vendas com diferentes percentuais
- **Habilidades:** Cálculos financeiros, incentivos

### 7. Calculadora de Média
- **Arquivo:** `7_calculadora_media.py`
- **Descrição:** Calcula médias aritméticas com múltiplos valores
- **Habilidades:** Processamento de listas, loops

## 🎯 Evolução do Aprendizado
Estes projetos representam um **avanço significativo** em complexidade em relação aos exercícios iniciais, incorporando:
- **Lógica mais sofisticada** (ano bissexto, IMC)
- **Cálculos do mundo real** (comissões, temperaturas)
- **Classificações baseadas em regras** (idade, IMC)
- **Aplicações práticas** diretamente úteis

## 🔗 Conexão com Data Science
Muitos desses conceitos são fundamentais para:
- **Pré-processamento de dados** (classificações, categorizações)
- **Feature engineering** (criação de novas variáveis)
- **Análise exploratória** (cálculos estatísticos básicos)
